## Repository overview

- Framework: Nuxt 4 + Vue 3 + TypeScript
- State: Pinia stores in `app/stores`
- API: Nitro server routes in `server/api`
- Database: MongoDB via Mongoose models in `server/models`
- Shared contracts: reusable types in `shared/types`
